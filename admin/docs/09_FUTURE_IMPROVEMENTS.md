# 09 — Admin Future Improvements

1. **Hardware Security Keys (WebAuthn/FIDO2)**:
   - Mandatory YubiKey / WebAuthn physical token enforcement for all super admin operations.
2. **Multi-Admin Quorum Approvals**:
   - High-risk operations (e.g. mass account deletions or refunds over $1,000) require approval from two distinct administrators before execution.
