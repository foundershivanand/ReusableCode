HOW TO USE IN ANOTHER FOLDER

Direct Consumption From GitHub

How an AI agent (Cursor, Claude Code, GitHub Copilot, Codex, Antigravity) works in a different folder using this library.

1

Add Package Dependency

In your new application folder, install the library directly from GitHub without cloning the repo:

# Using uv
uv add git+https://github.com/sh15aa/agentreusable.git

# Or pip
pip install git+https://github.com/sh15aa/agentreusable.git
2

Drop `AGENTS.md` in the Project Root

Tell any coding agent to reuse existing capabilities first instead of writing new boilerplate:

# In my-new-project/AGENTS.md
The project has access to: https://github.com/sh15aa/agentreusable
Module Registry: https://raw.githubusercontent.com/sh15aa/agentreusable/main/registry/modules.json

Rule: Reuse first, build second. Before scaffolding gateways, memory,
tools, or sandboxes, check registry/modules.json and import from `agentsreusable`.
3

Prompt Your AI Agent

Give your AI agent this prompt in the new project:

"Build [your agent goal]. Check the reusable library at https://github.com/sh15aa/agentreusable and its registry at https://raw.githubusercontent.com/sh15aa/agentreusable/main/registry/modules.json. Identify existing modules and assemble them instead of writing boilerplate."

4

Clean Assembled Code

The agent imports standardized modules directly:

import asyncio
from agent_factory.factory import AgentFactory
from templates.research_agent import create_research_agent

async def main():
    factory = AgentFactory()
    agent = create_research_agent(factory)
    result = await agent.run("Analyze latest AI agent architectures")
    print(result)

if __name__ == "__main__":
    asyncio.run(main())
SYSTEM DESIGN

10 Core Architectural Layers

A battle-tested production blueprint separating concerns across the entire AI agent lifecycle.

01

Identity & Config

Unique identity manifests, status lifecycle, environments, retry and cost policies.

02

LLM Gateway

Multi-provider routing by task complexity, streaming, and automatic fallback cascades.

03

Multi-Tier Memory

Working scratchpad, multi-turn compaction, semantic vector search, episodic history & hybrid RAG.

04

Hardened Tools

Central registry, AST-checked Python sandbox, SSRF-guarded browser & document parser.

05

Orchestration

Dynamic planning engine, parallel DAG workflow executor, and supervisor multi-agent messaging.

06

Human-in-the-Loop

Pause & resume approval queue intercepting HIGH & CRITICAL risk tool executions.

07

Validation

Pydantic structured output auto-repair, factual self-verification & citation provenance.

08

Security & Governance

RBAC permission matrices, PII redaction (email/phone/SSN), and zero-leak secret isolation.

09

Evaluation & Benchmarks

Golden test case datasets, LLM-as-Judge 1-5 rubric scoring & regression benchmark runners.

10

Observability & APIs

Hierarchical span tracing, security audit trail, operational metrics, and FastAPI SSE streaming.
