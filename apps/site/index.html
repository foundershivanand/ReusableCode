AI Coding Agents

How AI Agents Use This Directly from GitHub

Coding agents (Codex, Claude, Cursor, Antigravity) running in any folder can reuse modules directly without rewriting code.

1

Initialize in any External Project Folder

Run the global factory helper to generate the local AGENTS.md in your new app folder:

factory-pull setup-agent

This instructs the AI agent on the Core Rule: Reuse first, build second.

2

Direct Flutter Git Dependency (pubspec.yaml)

The agent links modules directly from your GitHub repo without copying files:

# In pubspec.yaml
mod_09_auth_module:
  git:
    url: https://github.com/sh15aa/Appreusable.git
    path: modules/mod_09_auth_module
    ref: main
