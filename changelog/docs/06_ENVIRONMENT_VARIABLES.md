| :--- | :--- | :--- | :--- | :--- |
| `DATABASE_URL` | String | Yes | - | PostgreSQL connection URL |
| `CHANGELOG_DEFAULT_AUDIENCE` | String | No | `ALL` | Default target audience for new posts |
| `CHANGELOG_AUTO_PUBLISH_CRON` | String | No | `*/5 * * * *` | Cron schedule for scheduled posts |
