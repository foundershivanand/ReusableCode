# Environment Variables: Multi-Language & i18n

| Variable | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `DEFAULT_LOCALE` | String | No | `en` | Fallback default system locale |
| `SUPPORTED_LOCALES` | String | No | `en,fr,fr-CA,ar,he,de,es` | Comma-separated list of enabled locale codes |
| `I18N_COOKIE_NAME` | String | No | `locale` | Cookie name for user locale preference |
