# 06 — Onboarding Environment Variables

| Variable | Type | Default | Description |
|---|---|---|---|
| `ONBOARDING_ENABLED` | boolean | `true` | Master switch for onboarding system |
| `ONBOARDING_DEFAULT_VERSION` | string | `v1` | Active flow version |
| `ONBOARDING_CACHE_TTL_SECONDS` | number | `3600` | Cache lifetime for flow definitions |
