# 02 — Referral Security & Self-Referral Fraud Defense

## 1. Self-Referral Prevention
- Self-referrals are prevented using multi-vector verification:
  - User ID matching: Affiliates cannot refer their own user accounts.
  - IP and device fingerprint correlation.
  - Payment method fingerprint matching.

## 2. Payout Account Security
- Modifying payout emails or payment destination accounts requires strong multi-factor authentication (MFA).
