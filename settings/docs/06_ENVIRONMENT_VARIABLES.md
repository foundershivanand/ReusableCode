# 06 — Settings Environment Variables

| Variable | Type | Default | Description |
|---|---|---|---|
| `DEFAULT_THEME` | String | `system` | System default theme (`light`, `dark`, `system`) |
| `DEFAULT_LOCALE` | String | `en` | System default locale code |
| `DEFAULT_TIMEZONE` | String | `UTC` | System default timezone identifier |
| `SETTINGS_CURRENT_SCHEMA_VERSION` | Integer | `3` | Current target schema version |
